# 项目介绍文案包

## 1. GitHub 仓库描述（About 栏，一句话）

> 基于 UCI Online Retail 真实电商数据（54万行交易），完成数据清洗、销售分析、RFM 客户分层、Apriori 购物篮分析与销售预测的完整数据作品集。

## 2. 简历项目描述（STAR 精简版，可直接粘贴）

**电商销售数据分析**（Python / pandas / scikit-learn / mlxtend）

- 基于英国零售商 54 万行真实交易数据，完成数据质量体检与清洗：识别并处理 26% 客户ID缺失、1.9% 退货订单、0.5% 异常单价，沉淀可复用的清洗口径
- 构建 RFM 客户价值模型，将 932 位客户划分为 6 类，定位出贡献 46% 收入的「重要价值客户」，输出差异化运营策略
- 使用 Apriori 算法挖掘购物篮关联规则，发现同系列商品强关联组合（Lift 最高 24.6），为捆绑销售与交叉推荐提供依据
- 对月度销售额构建 3 种预测模型并滚动回测，基于 MAPE 对比得出「短序列宜用简单模型」的量化结论，避免过拟合
- 全流程模块化封装（config/loader/analysis/visualize/modeling/report），`run_all.py` 一键复现，产出 10 张图表 + 自包含 HTML 报告 + 可执行 Notebook

## 3. 一句话项目介绍（HR / 非技术视角）

> 我用一家英国电商一年的真实订单数据（54 万条），回答了三个业务问题：钱是从哪个月、哪些客户、哪些商品组合赚来的，并用数据回答了「明年该重点维护谁、该把什么商品捆绑在一起卖」。

## 4. 项目数据卡片（放简历/作品集网站）

- 数据规模：541,909 行订单 / 4,372 位客户 / 4,070 种商品
